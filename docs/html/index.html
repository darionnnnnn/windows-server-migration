操作與交接文件中心

建議先讀完整操作手冊。以下是操作手冊與支援資料；文件為產生當下的離線快照，不會執行操作，也不代表目前工作區已達成本文所述狀態。

即時狀態以工作台顯示的來源、配對、revision、收據、階段結果及證據時間為準。機密原設定保存在受控材料。開發規劃不列入此文件中心；README、操作說明與參考資料仍依原始來源產生。

快速開始與日常操作

第一次使用或需要完成來源、管理、目標主機日常步驟時閱讀。

  • README認識工具用途、限制與從哪裡開始。來源：README.md
  • GENERAL-HOST-WORKFLOW一般主機、服務及排程工作負載的流程。來源：docs/GENERAL-HOST-WORKFLOW.md
  • OPERATIONS依操作階段查找入口、材料與責任。來源：docs/OPERATIONS.md

盤點清單與差異審閱

需要確認盤點範圍、軟體責任、支援項目及逐項差異時使用。

  • ENTERPRISE-MIGRATION-COVERAGE逐項確認企業情境是否納入及如何處置。來源：docs/ENTERPRISE-MIGRATION-COVERAGE.md
  • ENVIRONMENT-SOFTWARE-CONFIRMATION記錄軟體、版本、架構與手動補裝責任。來源：docs/ENVIRONMENT-SOFTWARE-CONFIRMATION.md
  • SUPPORT-MATRIX查閱目前支援範圍與限制。來源：docs/SUPPORT-MATRIX.json

復原、版本與資格

作業中斷、需查版本變更，或確認工具／環境資格狀態時使用。

  • IMPLEMENTATION-0.1查看現行實作狀態、已知限制與外部驗收項目。來源：docs/IMPLEMENTATION-0.1.md
  • RECOVERY-RUNBOOK作業失敗、中斷、對帳、續跑或回復時查閱。來源：docs/RECOVERY-RUNBOOK.md
  • RELEASE-NOTES-0.3了解版本變更及操作影響。來源：docs/RELEASE-NOTES-0.3.md
  • RELEASE-QUALIFICATION查看工具與環境資格證據及尚未驗證條件。來源：docs/RELEASE-QUALIFICATION.md
  • RELEASE-SBOM查閱發行套件的軟體材料清單。來源：docs/RELEASE-SBOM.json
