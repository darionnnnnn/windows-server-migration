0.4 實作狀態與外部驗證

更新：2026-10-15。第六輪備份／多共享／還原相依整合已提交，本機受控證據與未通過邊界分列，逐段 commit、適用版本及證據集中第六輪 PLAN (未產生或不安全的連結)。第五輪及更早的結果保留於各輪 PLAN；操作模板不能代勾，程式存在或 helper 測試通過不等於完整使用旅程已通過。

測試與交付規則

ToolRelease 收錄 README、docs 頂層文件與手冊資產、docs/html 使用者投影及支援／SBOM JSON；不遞迴收錄 archive 或 docs/plans，PLAN HTML 不進路由／索引／新發行包。既有頂層第三輪 PLAN Markdown 保留原交付契約，歷史引用仍需回專案原始碼查閱。

UI／src／入口 bytes 變更會更新 ToolFingerprint，執行中配對須以原版工具接續，不能熱換 UI。純文件變更不改工具指紋，但會更新發行包與文件 hash；新包必須核驗最終 bytes 並重新簽署，不能沿用舊簽章。

日常按改動影響重驗；Pipeline預設16小檔、取消8檔、報告2501列、Fleet十台各200、Spec200。5000分段及真實4GiB的特殊邊界保留；大容量／50k軟體／維護窗／RPO/RTO需代表性工作量與門檻，不能從合成數量推定。HTML分類列印最多2000列；完整軟體確認五格式不截斷資料。詳細測試操作見 README。
