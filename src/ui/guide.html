從左側「開始／繼續操作」進入。看完目前這一步，選擇要搬移的內容，再按「下一步」。可以按「上一步」檢查已保存的選擇。

目前可完成到哪裡：本版提供用途選擇、盤點、保存項目選擇、來源資料交接及開發者環境探測。完整自動備份、管理審閱與新主機還原導引尚未交付；需要執行後續步驟時，請本次搬移的資訊人員依完整手冊使用進階操作。下列三台電腦的流程說明包含這些進階步驟。

第一次開啟

  1. 在指定的電腦開啟整份工具資料夾，執行 Start-ServerMigration.cmd。它會開啟本機操作頁面；依公司允許的方式取得必要權限。
  2. 確認畫面上的電腦名稱。選擇「舊主機」、「新主機」或「整理搬移資料的電腦」。不確定時先向本次搬移負責人確認。
  3. 依畫面確認儲存位置。每台電腦使用自己的固定工作資料夾，交接材料與進度都保存在這裡。
  4. 從「開始／繼續操作」前進。工具會帶入可驗證的既有資料；需要你決定的欄位會說明原因。

本機網址只供這台電腦當次操作使用。跨電腦請傳遞交接材料。沒有瀏覽器時，可由支援人員使用同版工具的文字選單。

這台電腦的用途

舊主機

找出原有網站、排程、服務、資料與設定，記錄你要搬哪些內容。收到核准材料後，在這台電腦建立備份。

整理搬移資料的電腦

接收舊主機與新主機資料，核對差異、相依與責任，完成必要審閱及核准，再交付材料。

新主機

提供目前環境資料，接收核准備份，檢查可還原內容。由你單獨確認還原，之後驗證並另行確認啟用。

「這次要搬移的主機」顯示舊主機 → 新主機，代表目前這件工作。用途選擇不授予 Windows 權限，也不會遠端控制其他電腦。

跟著各自的步驟操作

在舊主機

  1. 掃描這台電腦。
  2. 逐項決定是否加入，或選擇自動加入工具支援的內容。
  3. 匯出盤點與已確認選擇，交給整理資料的人員。這份交接檔還不是備份，也不是核准。
  4. 收到核准材料後，檢查備份範圍與儲存位置，再明確開始備份。
  5. 查看實際結果及尚未完成內容，再交付備份材料。

在整理資料的電腦

  1. 匯入舊主機交接檔。檔案核對碼須由獨立可信管道取得，不能只相信檔案自己聲稱的值。
  2. 接收新主機身分與最新環境資料，確認目前工作。
  3. 核對差異、必要相依與設定範圍。實際責任人與外部證據仍由有權人員提供。
  4. 完成必要審閱與核准，交付給正確的舊主機及新主機。

在新主機

  1. 掃描目前環境，交給整理資料的人員。
  2. 接收核准材料與備份，檢查可還原項目及軟體準備狀態。
  3. 選擇先處理具備條件的內容，或等待補裝後再檢查。工具不會替你安裝軟體。
  4. 看完還原預覽，再單獨確認還原。檢查結果與待處理內容，必要時依同一工作續作。
  5. 驗證結果；正式啟用另有確認。還原完成不代表業務已可使用。

執行功能仍限定明確核准的隔離試行。目前沒有 Server 2016／2025 生產資格；本機測試與環境探測不會解除此限制。

逐項詢問與自動備份

每一步以網站、排程、服務、軟體設定或資料夾為單位。展開明細查看相關項目與檔案，不需要每個檔案都回答一次。未列舉的資料夾會明示範圍尚未列出完整檔案；明細不是備份成功證明。

預設加入已發現內容。選擇不加入時，工具提供可修改的白話理由並保存。一次確認剩餘項目時，先前排除的內容會保留；重新掃描後變更或新增內容需重新確認。

「自動加入所有可備份項目，不再逐項詢問」只用於本次備份。缺核准、容量、權限或必要資料時，仍停在「需要處理」，不會忽略後宣稱完整。它不授權還原或啟用。

備份包含工具支援並核准的資料與設定，保留已核准業務 DLL／EXE；不含整機映像、作業系統、System State，以及 Windows、IIS、Oracle Client、runtime 等安裝軟體本體。非 C 槽依原有受控交接通道處理；需要另一台電腦時依畫面交接。

如何判斷完成

左側取得有效盤點後才出現「掃描結果」，有持久備份或還原紀錄後才出現對應結果。結果屬於目前工作；換工作後重新核對。

需要處理
缺條件、證據或確認，依下一步補齊。
部分完成
已有部分結果，仍有缺項。查看明細，不當作完整成功。
已取消／失敗
保留工作資料夾與紀錄，查看停止位置及恢復方式。
完成
只代表所列階段完成。掃描、備份、還原、啟用及業務接受是各自不同階段。

步驟進度不是備份覆蓋率。C 槽與非 C 槽、檔案與設定、軟體準備與業務結果須分別核對。

關閉、取消與重試

  • 重新整理或關閉頁面不會取消作業。已保存的選擇與進度可以繼續；尚未提交的輸入可能需要重填。
  • 關閉 PowerShell 視窗會停止本機工具。重啟後保留同一工作資料夾，先查原作業及中斷紀錄。
  • 按取消只是提出要求。等顯示實際已取消，才代表已到安全停止點。
  • 提交後逾時或斷線，先查同一筆作業，不連按開始建立重複作業。無法確認結果時，保留作業編號交給支援人員。
  • 其他視窗更改工作或資料時，依提示重讀，不忽略過期提示。

執行中的核准材料綁定當時整份工具內容。不要在工作途中替換工具，也不要自行編輯內部 JSON 或清空工作資料夾。

開發者環境探測

左側「開發者環境探測」可單獨一鍵執行，不必先建立搬移工作。它收集全部適用的本機資料，產生報告及資料包供後續開發查問題，不會自動上傳。

報告明列完成、部分完成、失敗與不適用項目。資料包中的敏感識別資料會遮罩；本機原始證據保存在受保護資料夾。探測不是核准或備份；交付資料仍遵循公司資料處理規則。

遇到問題

電腦或搬移工作不對

先停止提交，確認電腦與工作資料夾。多個視窗共用同一程序，工作可能被其他視窗切換。

軟體未安裝或版本不同

由負責人準備，再重新掃描。只修改選用版本不代表已安裝；舊設定保存成功也不代表新版能直接讀取。

檔案位置有衝突

查看原位置、目的位置與原因。工具不合併既有文件；不要清空共用目錄或盲目覆寫新主機內容。

無法開啟或權限不足

保留錯誤識別碼，交由公司支援人員檢查權限、部署與執行政策。不要自行關閉防護、修改政策或開放遠端連線。
